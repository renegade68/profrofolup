# 검증 범위와 재실행 확인

## 기존 계산 코드의 검증

2026-10-30의 내부 통합 검증에서는 빈 결과 폴더에서 원자료 → 패널 → 7개 분석 단계 → 표·그림을 실행했습니다. Stata/Mata 결과를 봉인된 이전 결과와 비교하여 CSV 233개, 중간·최종 비교행 3,524,539행이 허용오차 안에서 일치했습니다. 최대 정규화 차이 `abs(new-reference)/max(1,abs(reference))`는 약 `1.02e-14`였습니다. 이 행 수는 반복 비교를 포함하며 고유 표본 크기가 아닙니다.

공개용 구성에서는 해당 계산 코드를 유지하고, 로컬 데이터·제3자 바이너리·공유 재표집 파일을 제외했습니다. 원자료 ZIP 정규화, 재표집 입력 재생성, 환경변수로 실행 경로 지정, 입력 점검 및 문서를 추가했습니다. 이 포장 변경의 검증과 원래 전체 분석의 통합 검증을 구분합니다.

## 저장소 구성의 검증

- 준비 도구로 원본 CSV 19개의 바이트를 보존하고 열 정의를 대조했습니다.
- 새 로컬 정규화 ZIP에서 Stata 원자료·동태·전략 패널을 실행하여 기존 검증본과 CSV 바이트 일치를 확인했습니다.
- KM·공통경계·조건부 추격비의 재생성 식별자 순서와 재표집 가중치/인덱스를 기존 입력과 전수 비교했습니다.
- 변경된 KM 준비 도구 호출을 Stata에서 실행하고 결과를 대조했습니다.
- 원자료·가공자료·결과·로그·기업 식별자·외부 바이너리·개인 경로를 출판 파일 목록에서 제외했습니다.

로컬 입력을 준비한 뒤 다음 명령으로 출판 경계·소스 구문을 검사할 수 있습니다. 이 검사는 통계적 타당성 또는 전체 데이터 재현 검사를 대신하지 않습니다.

```sh
python3 tests/check_release.py
python3 tools/prepare.py check
```

전체 실행은 `zsh run_all.zsh`입니다. Stata 프로세스의 종료코드 외에 로그의 `r(n)` 오류와 완료 표지를 확인합니다. `RAW_PANEL_COMPLETE`, `STATA_GLOBAL_STAGE4_COMPLETE` 등 각 단계 표지가 있고 마지막에 `KSOI_FULL_RUN_COMPLETE`가 있어야 합니다.

## 결과 해석과 자료판 차이

본 분석의 분류가능 제조업 표본은 9,039개 기업·49,780개 기업-연도, 양수 DEA 완전사례는 48,531개입니다. 분석별 사전·사후 관측요건과 참조경계가 달라 표본 수가 서로 다릅니다.

원저자의 비공개 재표집 절차와의 완전 동일성, 자산의 공식 평가·변수 매핑, 잠정 가격 대응은 별도 확인 과제입니다. 후속 다운로드에서 표본 또는 가격 개정이 발생할 수 있습니다. 2017–2023년 선행연구와의 62개 관측 차이는 기록된 비교 차이이며 원인이 확인된 오류로 취급하지 않습니다.

현재 저장소에는 원자료·기준 결과를 담지 않으므로, 독립 이용자의 결과가 원고와 정확히 같은지는 본인이 확보한 자료판과 출력으로 확인해야 합니다. 버전·다운로드 기록·코드 커밋 SHA를 보존하십시오.
