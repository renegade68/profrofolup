# 데이터 접근 및 로컬 준비

## 1. 기업활동조사

1. [마이크로데이터 통합서비스(MDIS)](https://mdis.kostat.go.kr/)에 접속하여 본인의 계정과 이용 목적에 따라 공공용 기업활동조사 자료를 신청·다운로드합니다. 포털 주소는 기관 개편 등에 따라 리디렉션될 수 있습니다.
2. **2006–2024년** 전체 연도의 CSV와 해당 코드북/변수설명·Stata 제공 구문을 확보합니다. 본문 분석은 2017–2024년이지만 과거 자료는 기업키 연결과 시차 구성에 필요합니다. 다운로드 단계에서는 제조업·AI 기업만 미리 선별하지 않습니다.
3. 다운로드 일시, 선택한 연도·제공 유형·파일명을 로컬에 기록하고 원본 ZIP을 보존합니다. 논문에 사용한 판본의 추출일은 **2026-08-01**입니다. 새 판본은 사후 보완·수정 등으로 관측 수가 달라질 수 있으며, 차이의 원인을 자료 없이 단정하지 않습니다.
4. `tools/prepare.py init --raw-dir ...`로 원본 ZIP 또는 연도 이름으로 시작하는 CSV를 읽습니다. 도구는 CP949 인코딩, 열 수, 사용 변수의 헤더를 기준 대응표와 대조합니다. CSV 바이트는 바꾸지 않고 ZIP 내부 이름만 `2006.csv`처럼 정규화합니다. 다른 자료판에서 열 순서가 바뀌었다면 코드북과 대응표를 먼저 검토해야 합니다.

로컬 ZIP 이름의 `75764`, `86378`, `43412`, `82803`은 기존 분석의 연도 묶음 식별자입니다. 새 다운로드에 같은 번호가 붙을 필요는 없습니다. 준비 도구가 2006–2009, 2010–2014, 2015–2019, 2020–2024년으로 다시 묶습니다.

변수 위치·정의는 `run/KSOI_stata_migration_20261030/code/metadata/RAW_METADATA.json` 및 `columns_YYYY.do`에 있습니다. 기업체패널키/BR 패널키, 산업분류, 종사자, 유형자산, 매출·비용·인건비 등 재무항목, 9개 기술 활용항목을 사용합니다. 이 대응표에는 개별 기업의 관측값이나 식별자 목록이 없습니다.

## 2. 기본 가격자료

기존 분석은 한국은행의 [생산자물가지수 공표자료](https://www.bok.or.kr/portal/bbs/B0000501/view.do?nttId=10095836)에 첨부된 `bok_ppi_2025_annual_source.xlsx`로 로컬 보관한 파일의 「2.생산자물가지수」와 「3.국내공급물가지수」 표를 사용했습니다. 이 이름은 연구자가 보관한 로컬 이름이며 배포 파일명과 다를 수 있습니다. 같은 계열은 [ECOS](https://ecos.bok.or.kr/)에서도 확인할 수 있습니다.

연간 **2020=100** 기준의 제조업 생산자물가지수, 중간재 국내공급물가지수, 최종재 국내공급물가지수를 확보하고 아래 열 이름으로 UTF-8 CSV를 저장합니다. 원 분석 입력은 2015–2025년이고 추정에는 2015–2024년을 사용합니다. 원자료·표명·추출일을 따로 보관하십시오.

파일명: `bok_annual_deflators_2020_100.csv`

| 열 | 내용 |
|---|---|
| `fiscal_year` | 연도 |
| `output_manufacturing_ppi` | 제조업 생산자물가지수 |
| `intermediate_goods_dspi` | 중간재 국내공급물가지수 |
| `capital_final_goods_dspi` | 최종재 국내공급물가지수: 기본 자본 가격 대리변수 |

원 공표자료와 최신 ECOS 값의 수정 여부를 확인합니다. 기본 자본가격 대리변수와 아래 제조업 투자 디플레이터 후보는 서로 다른 사양입니다.

## 3. 부록 가격 민감도 자료

아래 도구는 공식 ECOS 공개 API에서 가격 관측값을 **사용자의 로컬 폴더에** 내려받습니다. 저장소에는 가격 관측값을 넣지 않습니다. API 반환 구조나 계열이 바뀌면 오류를 확인하고 공식 계열과 대조하십시오.

```sh
python3 tools/fetch_prices.py
python3 tools/fetch_exports.py
python3 tools/fetch_capital_export.py
```

생성된 `local_price_downloads/results/`의 다음 세 CSV와 위 기본 가격 CSV를 한 로컬 폴더에 모아 `--price-dir`로 지정합니다.

| 파일 | 필요한 열 | 계열/구성 |
|---|---|---|
| `partial_industry_ppi.csv` | `industry_mid_num,year,ppi` | ECOS `404Y014`, 연간 2015–2024, 코드의 15개 업종 대응 후보 |
| `capital_candidate.csv` | `year,implicit_investment_deflator` | `200Y135`와 `200Y136`, `1100103`, 제조업 명목/실질 총고정자본형성 비율×100 |
| `export_candidate.csv` | `industry,year,export_price` | `402Y014`, 원화 기준 `W`, 대응 가능한 수출가격 후보 |

업종-상품 대응은 **잠정 대응**이며 원저자 또는 공식 KSIC 대응표로 확인된 매핑이 아닙니다. 자산 잔액에 투자 흐름의 디플레이터를 적용한 결과도 민감도 분석입니다. 공식 자산 항목 대응의 미확인 범위와 함께 해석해야 합니다.

## 4. 재표집 파일은 업로드하지 않고 재생성

- KM: Python 표준 `random.Random(1985)`의 추출 순서를 사용하며 문턱별로 난수 흐름이 이어집니다.
- 공통경계: R의 Mersenne-Twister/Inversion/Rejection, seed 20261007(기업 재표집), 20261008(동일 표본수 민감도).
- 조건부 추격비: NumPy `default_rng`의 multinomial 가중치, 각 분석의 고정 seed 및 10,000회 반복.

세 도구는 새로 만든 로컬 기업·사건 목록에서 순서/가중치를 생성합니다. `run_all.zsh`와 KM 단계가 필요한 시점에 호출합니다. 식별자가 포함된 목록과 가중치, 독립 비교용 계산 결과는 `validation/` 아래 로컬에만 남습니다. 원자료 제공기관의 이용조건에 따라 관리하십시오.
